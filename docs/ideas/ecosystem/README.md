# Écosystème « open »

Classement de 186 projets portant le nom ou l'esprit « open » (OpenRouter, OpenStreetMap, OpenSSH, OpenSSL, OpenTUI, OpenGL, Vulkan, OpenAI, OpenAPI, ...), établi avec Context7 et l'API GitHub. Une passe critique a ajouté GLFW, OpenResty, OpenH264, OpenJPEG, Open vSwitch, OpenXLA et Mesa.

- Données : [`ecosystem.json`](ecosystem.json) (`items`, `absorb_plan`, `pin_plan`) ; vue tabulaire : [`ecosystem.md`](ecosystem.md).
- Domaines : ai 53, geo-data 29, security-net 29, graphics 27, dev-tools 24, platform-os 16, engine 4, media 3, licensing 1.
- Modes par projet : absorb 51 (aplati dans `ecosystem/<owner>-<name>`), pin 72 (rev seule dans le lock), reference 35 (spec ou docs), skip 28 (archivé, mort ou hors périmètre).
- Règle de taille appliquée : au-delà de 300 Mo, pin au lieu d'absorb (ex. Open Interpreter 318 Mo, OpenClaw annoncé à 14,9 Go par GitHub).

Limites connues : quota mensuel Context7 épuisé pendant le run, donc des identifiants Context7 manquent ; Mesa (GitLab) non vérifié.
