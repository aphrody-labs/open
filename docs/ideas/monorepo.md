## How it is built

- Import: `git clone --depth 1` then `git archive HEAD | tar -x` (upstream history not kept, revision in the lock). Files over 50 MB and files whose names Windows refuses are dropped and listed in `dropped_files` with a reason. Script: [`scripts/sync.ts`](../../scripts/sync.ts).
- Secrets: gitleaks summary in [`docs/security/`](../security/).
- Bun workspace: root `package.json`, nested globs, hoisted catalogs, `bunfig.toml` isolated linker; generated by `scripts/workspaces.ts` ([`docs/workspaces.md`](../workspaces.md)).
- Cargo workspace: root `Cargo.toml` for leaf crates; nested upstream workspaces (rune, opentunnel, codex-rs, niri, ...) stay standalone and are listed in `exclude`. `.cargo/config.toml`: `lto = "fat"`, `codegen-units = 1`, `opt-level = 3`, `strip = "symbols"`.
- Bun AOT: `scripts/aot.ts` (`just aot`) compiles the workspace CLIs.
