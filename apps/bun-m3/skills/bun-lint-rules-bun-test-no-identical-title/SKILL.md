# bun:test/no-identical-title

When two tests in the same block share a title, a failure report doesn't tell you which one failed, and filtering by name runs both. The second one is often a copy that kept the old title.

Titles are compared inside one block. The same title in two different `describe` blocks is fine.

{/* Generated by src/codegen/lint-rule-docs.ts. Do not edit this section. */}

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"bun:test/no-identical-title" = "error" # or "warn"
```

{/* End of the generated section. */}

## Examples

Reported:

{/* bad */}
```ts

describe("parsePrice", () => {
  test("reads a number", () => {
    expect(parsePrice("12")).toBe(12);
  });

  test("reads a number", () => {
    expect(parsePrice("12.50")).toBe(12.5);
  });
});
```

Two `describe` blocks next to each other are compared the same way:

{/* bad */}
```ts

describe("cart", () => {
  test("adds an item", () => {});
});

describe("cart", () => {
  test("removes an item", () => {});
});
```

Not reported:

{/* good */}
```ts

describe("parsePrice", () => {
  test("reads a whole number", () => {
    expect(parsePrice("12")).toBe(12);
  });

  test("reads a decimal", () => {
    expect(parsePrice("12.50")).toBe(12.5);
  });
});

describe("formatPrice", () => {
  test("reads a whole number", () => {
    expect(formatPrice(12)).toBe("12.00");
  });
});
```

Only plain string titles are compared. A title built from a variable is skipped, and so is `.each`, which fills in the title for each row:

{/* good */}
```ts

test.each([1, 2])("doubles %i", n => {
  expect(double(n)).toBe(n * 2);
});

test.each([-1, -2])("doubles %i", n => {
  expect(double(n)).toBe(n * 2);
});

test("rounds " + mode, () => {});
test("rounds " + mode, () => {});
```

`test.if()`, `test.skipIf()` and the other conditional forms are skipped too, because a pair with opposite conditions is one test:

{/* good */}
```ts

const isWindows = process.platform === "win32";

test.if(isWindows)("finds the home directory", () => {
  expect(homeDirectory()).toStartWith("C:");
});

test.if(!isWindows)("finds the home directory", () => {
  expect(homeDirectory()).toStartWith("/");
});
```
