# react/no-children-prop

You can write children in two places: between the tags, or as a prop named `children`. If an element has both, the children between the tags win and the prop is dropped without a warning.

Nest children between the tags. With `React.createElement`, pass them as the third and later arguments.

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"react/no-children-prop" = "error" # or "warn"
```

Every option, set to its default:

```toml bunfig.toml
[lint.rules]
"react/no-children-prop" = ["error", {
  allowFunctions = false,
}]
```

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `allowFunctions` | `false` | Allow a function as the `children` prop, and report a function that's nested between the tags instead. |
