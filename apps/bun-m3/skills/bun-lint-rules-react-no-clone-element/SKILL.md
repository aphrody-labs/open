# react/no-clone-element

`cloneElement` adds props to an element that was created somewhere else. Anyone reading `` can't see that it receives `isSelected`, and the extra props are lost as soon as someone wraps the child in another component. Pass the data with a render prop or with context instead.

The rule only reports a `cloneElement` that's imported from `"react"`.

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"react/no-clone-element" = "error" # or "warn"
```

## Examples

Reported:

{/* bad {"count": 2} */}
```jsx

function List({ children, selected }) {
  return Children.map(children, (child, i) => cloneElement(child, { isSelected: i === selected }));
}

const disabled = React.cloneElement(, { disabled: true });
```

{/* good */}
```jsx

  return items.map((item, i) => renderItem(item, i === selected));
}

   }
  />
);
```
