# @next/next/no-duplicate-head

Each `` from `next/document` renders a whole `<head>`, with the styles and scripts Next.js adds for the page. A second one repeats all of that. Put your tags in one ``.

The rule reports any file with two or more `` elements, if `Head` is an imported name.

{/* Generated by src/codegen/lint-rule-docs.ts. Do not edit this section. */}

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"@next/next/no-duplicate-head" = "error" # or "warn"
```

## Examples

Reported:

{/* bad */}
```jsx

  return (
    
      
        <meta name="theme-color" content="#111111" />
      
      
        <link rel="icon" href="/favicon.ico" />
      
      <body>
        
        
      </body>
    
  );
}
```

Not reported:

{/* good */}
```jsx

  return (
    
      
        <meta name="theme-color" content="#111111" />
        <link rel="icon" href="/favicon.ico" />
      
      <body>
        
        
      </body>
    
  );
}
```

## When not to use it

The rule doesn't check where `Head` comes from. Next.js merges several `` elements from `next/head`, but two of them in one file are still reported:

{/* bad */}
```jsx

  return (
    <article>
      
        <title>{post.title}</title>
      
      {post.draft && (
        
          <meta name="robots" content="noindex" />
        
      )}
    </article>
  );
}
```
