# bun:test/warn-todo

`test.todo` marks a test that nobody has written yet, or one that doesn't pass yet. `bun test` still passes, so it's easy to forget, and the behavior it names stays untested.

{/* Generated by src/codegen/lint-rule-docs.ts. Do not edit this section. */}

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"bun:test/warn-todo" = "error" # or "warn"
```

{/* End of the generated section. */}

## Examples

Reported:

{/* bad {"count": 2} */}
```ts

test.todo("refunds the order");

describe.todo("checkout");
```

Not reported:

{/* good */}
```ts

test("refunds the order", () => {
  expect(refund(order).total).toBe(0);
});
```

## When not to use it

If you use `.todo` to plan tests and read the list in the test output, this rule only repeats it.
