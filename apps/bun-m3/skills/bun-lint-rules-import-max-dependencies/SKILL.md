# import/max-dependencies

A file that imports from many modules usually does too many things, and a change in any of those modules can break it. This rule reports a file that depends on more than `max` modules, 10 by default.

Each module counts once, no matter how many statements import from it. `import`, `export ... from`, `import()` and `require()` all count.

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"import/max-dependencies" = "error" # or "warn"
```

Every option, set to its default:

```toml bunfig.toml
[lint.rules]
"import/max-dependencies" = ["error", {
  max = 10,
  ignoreTypeImports = false,
}]
```

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `max` | `10` | The number of modules a file can depend on. |
| `ignoreTypeImports` | `false` | Don't count `import type` statements. |

If you pass options, always include `max`. The default of 10 only applies when there are no options at all. With `{ "ignoreTypeImports": true }` alone, nothing is reported.
