# react/jsx-pascal-case

Components named `UserCard`, `User_Card` and `USERCARD` in one codebase are hard to search for and easy to mix up with constants. This rule wants one style: a capital first letter, no underscores, and at least one lowercase letter or digit.

Tags that start with a lowercase letter are HTML elements, so the rule skips them. One-character names, such as ``, are allowed. In ``, the rule checks each part.

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"react/jsx-pascal-case" = "error" # or "warn"
```

Every option, set to its default:

```toml bunfig.toml
[lint.rules]
"react/jsx-pascal-case" = ["error", {
  allowAllCaps = false,
  allowLeadingUnderscore = false,
  allowNamespace = false,
  ignore = [],
}]
```

## Examples

Reported:

{/* bad {"count": 2} */}
```jsx
const page = (
  <User_Card>
    
  </User_Card>
);
```

Not reported:

{/* good */}
```jsx
const page = (
  
    
    <H1 />
  
);
```

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `allowAllCaps` | `false` | Also allow names in capitals, with underscores between words: `<NAV_BAR />`. |
| `allowLeadingUnderscore` | `false` | Allow one underscore before the name: `<_Button />`. |
| `allowNamespace` | `false` | In ``, only check `Form`. |
| `ignore` | `[]` | Names to skip. Globs such as `"*_DEPRECATED"` work. |

{/* good {"options": [{"allowAllCaps": true}]} */}
```jsx
const nav = <NAV_BAR />;
```

{/* bad */}
```jsx
const button = <_Button />;
```

{/* good {"options": [{"allowLeadingUnderscore": true}]} */}
```jsx
const button = <_Button />;
```

{/* bad */}
```jsx
const field = ;
```

{/* good {"options": [{"allowNamespace": true}]} */}
```jsx
const field = ;
```

{/* good {"options": [{"ignore": ["*_DEPRECATED"]}]} */}
```jsx
const dialog = <Modal_DEPRECATED />;
```
