# react/jsx-props-no-spread-multi

Spreading the same object a second time adds nothing new, and it overwrites every prop written between the two. In ``, `disabled` is lost if `props` also has a `disabled`. It's almost always a leftover from a merge or a copy.

`--fix` removes every spread of the variable except the last. With an ESLint config there's no fix, same as in `eslint-plugin-react`.

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]

```
