# react/jsx-fragments

`<>...</>` and `...` do the same thing. Mixing them makes readers wonder if there's a difference. By default the rule asks for the short form.

A fragment with a prop such as `key` is never reported, because the short form can't take props. A plain `` counts if `Fragment` comes from `"react"` or from `React`.

`--fix` rewrites the fragment to the other form.

## Configure

Off by default. To turn it on:

```toml bunfig.toml
[lint.rules]
"react/jsx-fragments" = "error" # or "warn"
```

Every option, set to its default:

```toml bunfig.toml
[lint.rules]
"react/jsx-fragments" = ["error", "syntax"] # "syntax" or "element"
```
